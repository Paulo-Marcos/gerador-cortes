# examples/

Arquivos de referência que mostram **o que você precisa criar** para configurar o projeto para o seu canal.

Cada pasta corresponde a um tipo de configuração canal-específica:

- `docs/` — Guias editoriais e de identidade visual (thumbnail, estilo, persona)
- `skills/` — Skills do Claude adaptadas ao seu canal

## Como usar
Esses arquivos mostram a estrutura e o nível de detalhe esperado — não são código de aplicação.
Copie, adapte e preencha com as informações do seu canal.
