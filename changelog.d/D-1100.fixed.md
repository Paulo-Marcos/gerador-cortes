- **The reason a ChatGPT cover did not come back survives a restart.** The
  robot's queue kept each cover's step and stop reason in memory only, so a
  refusal from ChatGPT ("pode violar nossas diretrizes…") vanished when the
  backend restarted, and the vertical TikTok cover stayed missing with nothing
  on the card while RN-26 held the post. The last request of each cover is now
  written to the channel database at every step, and the card reads it back
  when the queue no longer has it. A request that was still queued or drawing
  when the app restarted shows as stopped, asking to try again, instead of
  "Gerando no ChatGPT…" or nothing (D-1100).
