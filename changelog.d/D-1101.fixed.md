- **A struck cut stays struck when asked to be struck again, and a file in use
  is counted once.** A request to set an already struck cut to "rejeitado" no
  longer undoes the strike behind the scenes: the stage it came from, its count
  as a deleted proposal and its released raw clip stay as they were, and no raw
  clip is generated for it, so "Trazer de volta" still returns it to where it
  was. When a file is in use while striking, the notice now says "1 arquivo em
  uso ficou no disco" instead of counting that file twice. (D-1101)
