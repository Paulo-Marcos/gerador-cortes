- **The final render waits for the validated scene plan, and the Filters tab
  left Post-production.** "Render final" (and "Render again") stays disabled
  until the scene plan is validated, with the reason beside it ("Renderizar
  libera quando o plano estiver validado"), and enables the moment the plan is
  validated, without a reload. The backend refuses the same request with a 400
  that says what is missing, so a request from any other path is held too; a
  partial render (grade or overlays only) is still free. An empty plan can
  be validated too: what unlocks the render is the operator's decision, not
  having scenes (RN-37). The Filters
  tab is gone from Post-production: the render filter belongs to the channel
  (RN-25), so the panel now shows a "Filtro do canal (global)" line with the
  current filter and a link to Channels → Application, where it is edited
  (`/canais?aba=aplicacao` now opens that tab). "Fonte dos cards", which only
  lived inside the Filters tab, moved to the Layout tab (D-1072).
