- **Focus mode in the cut editor.** `Shift+F` (or the new button on the editor
  strip) hides the whole shell — rail, top bar, step track, context column,
  header, action bar, the segments column and the timecode strip — and puts the
  browser in full screen, leaving only the player and the waveform at the
  largest height. The same shortcut or Esc leaves; leaving full screen through
  the browser also leaves the mode, and if the browser refuses full screen the
  shell focus still applies. Nothing is saved: each column returns exactly as
  it was left. Approve and reject stay on `A` and `R`. The shortcut is
  reassignable on the Shortcuts page.
