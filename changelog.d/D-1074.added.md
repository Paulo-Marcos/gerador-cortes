- **Ask the AI to adjust one scene in Post-production.** The selected scene card
  now has "Pedir ajuste desta cena à IA" ("ex.: encurte para caber em duas
  linhas") and a "Pedir ajuste" button: the operator asks for a change to that
  scene without generating the whole plan again. The request reuses the scene
  generation path: the channel's scene scaffold and scene skill, the subtitles
  around the scene, and the same provider that generated the current plan
  (Gemini if the plan came from Gemini, otherwise Claude). The answer is a
  proposal: the card shows before and after for each changed field, with
  "Aceitar" and "Descartar". Only "Aceitar" writes, and only that scene, and it
  clears the plan validation like any other change. If the plan changed since
  the request, the server refuses and says so. What the AI does not mention stays
  as it was (portrait, card layout, and the timing, when it returns the same
  subtitle and duration). Manual and struck scenes get no request field. While
  the AI works, the card says so and offers "Cancelar", which kills the
  `claude -p` process (D-1045); with Gemini it frees the cut at once, but the
  `agy` process still runs to its timeout, the gap D-1045 left open. Adjusting a scene and generating the whole plan
  never run together on the same cut: each refuses the other upfront, and
  "Gerar cenas" is disabled during an adjustment. Each adjustment is counted in
  the AI telemetry as its own step, `ajuste-de-cena` (RN-40) (D-1074).
